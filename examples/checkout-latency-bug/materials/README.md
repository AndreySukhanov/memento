# Materials (not included)

The five memory files in this example cite files in this folder - a support-ticket
export, a production trace, two benchmark runs, a meeting note. They are not shipped:
they would be several megabytes of invented data, and nothing in the method depends on
reading them.

What matters is that they are **cited by name and date** everywhere a fact came from
them. That is the point being illustrated: "the API returns 403" is a trap, and
"the API returned 403 on 2026-06-12, per Dan's message in #checkout" is memory.

In a real task folder this directory holds the raw material untouched - chat exports,
logs, screenshots, dumps - and `TASKS.md` lists every file with a one-line annotation,
including the ones that were not used.
